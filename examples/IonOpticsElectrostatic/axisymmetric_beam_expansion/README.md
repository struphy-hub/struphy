# Axisymmetric round-beam expansion

A cold, uniform proton beam drifts through a grounded cylindrical tube. The
axisymmetric wedge calculation is compared with the paraxial envelope equation
obtained independently from Gauss' law. This closes the cylindrical
space-charge verification gap: it exercises the wedge volume measure,
trajectory charge deposition, Poisson solve, and particle push together.

Run with:

```sh
.venv/bin/python axisymmetric_beam_expansion.py
```
